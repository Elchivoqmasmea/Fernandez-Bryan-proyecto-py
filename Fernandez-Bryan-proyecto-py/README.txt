DESCRIPCIÓN DEL PROYECTO
----------------------------------------

Este programa es un sistema de gestión de empleados que permite registrar,
consultar y administrar la información del personal de una empresa.
Permite agregar empleados, verlos por departamento, calcular la nómina
total, mostrar el mayor salario, contar empleados con nombres largos
y eliminar registros por cédula.

El propósito es aplicar los conocimientos de Programación Orientada
a Objetos, estructuras de control, ciclos, funciones y manejo de
listas en Python.
